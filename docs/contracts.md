# Internal construction contracts

Imports use `.js` extensions. Async I/O; strict types in `src/types.ts`. No lane modifies these contracts without messaging author.

- store.ts: `hashBytes(body:Uint8Array):{sha256:string,sri:string}`; `saveSource(stateDir:string,body:Buffer):Promise<{sha256:string,sri:string}>`; `readSource(stateDir,hash):Promise<Buffer>` verifies hash; `readManifest(stateDir):Promise<Manifest>`; `writeManifest(stateDir,manifest):Promise<void>`; `readReview(stateDir,fingerprint):Promise<Review|undefined>`; `writeReview(stateDir,review):Promise<void>`; `readApprovals(stateDir):Promise<Approval[]>` missing => []; `writeApprovals(stateDir,approvals):Promise<void>`; `appendEvent(stateDir,event:Record<string,unknown>):Promise<void>`; `reviewFingerprint(hash,provider,model,promptVersion?,policyVersion?):string`; `readAllReviews(stateDir):Promise<Review[]>`; export `validateReviewResult(value:unknown):ReviewResult`; `atomicWrite(path:string,data:string|Buffer):Promise<void>`.
- network.ts: `fetchResource(url:string,options?:FetchOptions):Promise<FetchResult>`; `isPublicAddress(address:string):boolean`. Only --allow-local test opt-in permits loopback (not all private networks). This opt-in appears prominently in reports.
- discovery.ts: `parseReferences(html:string,pageUrl:string):ScriptReference[]`; `discover(options:ScanOptions):Promise<Manifest>` saves sources into stateDir (default .script-harbor), but pipeline writes manifest/report. Return errors in manifest; never silently swallow parse/fetch errors. `relocationReasons(source:string,kind:Artifact['kind']):string[]`.
- rewrite.ts: `rewriteHtml(html:string,pageUrl:string,artifacts:Artifact[],publicPath:string):string` uses parser offsets, preserves unrelated HTML. `vendorArtifacts(stateDir:string,artifacts:Artifact[],publicDir:string,publicPath?:string):Promise<Record<string,string>>` verifies source bytes, writes sha.js into publicDir/<publicPath default vendor/script-harbor>, maps source URLs to public URL; pipeline responsible for approvals before calling. `protectDirectory(dir:string,origin:string,stateDir:string,artifacts:Artifact[],publicPath?:string):Promise<void>` validates/stages all pages+source copies before changing build, no symlink path traversal.
- analysis.ts: `analyzeSource(source:string):Finding[]`; `buildPrompt(source:string):{system:string,user:string}`. Prompt review only source, no changing URL/context to preserve content-addressed caching; approval is bound to manifest URL during protect via matching saved URL->hash.
- providers.ts: `requestReview(source:string,options:ReviewOptions):Promise<ReviewResult>` handles providers tool-free; throws for external (use import). No source truncated. Optional endpoint/apiKey injected in tests, HTTPS required except loopback HTTP test fixture. Strict response schema + refusal/status validation.
- pipeline.ts: `scan(options:ScanOptions):Promise<Manifest>`; `review(options:ReviewOptions):Promise<Review[]>`; `approve(hash:string,options:{stateDir?:string,reviewer:string,reason:string,allowRehost?:boolean,fingerprint?:string}):Promise<Approval>`; `check(options?:{stateDir?:string,provider?:Provider,model?:string,live?:boolean,allowLocal?:boolean}):Promise<void>`; `vendor(options:{stateDir?:string,publicDir:string,publicPath?:string}):Promise<Record<string,string>>`; `protect(options:ProtectOptions):Promise<Manifest>`; export/import functions as lane4 chooses, document.
- report.ts: `writeReport(stateDir:string,manifest:Manifest):Promise<void>` report review/approval status per artifact; escaped Markdown untrusted fields, local JSONL events separate.
- integrations.ts: `initProject(options:{cwd?:string,framework:string,origin:string}):Promise<void>` five presets; export `astro(options)` and `vite(options)` thin hooks with structural types (no mandatory framework dependencies). Failed scan/protect throws to fail build.

Testing: node:test + assert, test/*.test.ts. Browser E2E test/*.e2e.ts (separate). Tests use temporary directories, clean in finally. Do not share fixture state across tests. Only parent edits package/config/types/spec. Lanes do not commit or rename shared title.
